# Course Slides

This is Kosuke Shimamoto's course-slide format for Quarto and Typst.

It is adapted from
[Quarto Clean Typst](https://github.com/kazuyanagimoto/quarto-clean-typst)
by Kazuharu Yanagimoto. The adapted format uses Helvetica Neue, circular list
markers, and the reusable `course-quote` quotation treatment.

Use it in a Quarto document with:

```yaml
format: course-slides-typst
```
